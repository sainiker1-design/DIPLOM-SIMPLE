# NEXUS ARENA

Сайт киберспортивного клуба: игровые зоны, турниры, бронирование мест и просмотр заявок.

## Запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив целиком и откройте `index.html` в браузере. Установка дополнительных программ не требуется.

## Файлы

- `index.html` — главная страница и формы.
- `assets/css/style.css` — оформление.
- `assets/js/main.js` — меню, бронирование и заявки.
- `assets/js/storage.js` — сохранение данных.
- `assets/images/` — локальные фотографии.

Заявки сохраняются только в текущем браузере через localStorage. Отправка администратору и оплата не выполняются.
